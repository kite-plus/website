Kite 0.1.1 发布了。这一版主要改的是写作后台：写文章时正文占满整个页面，主题设置有了自己的页面，仪表盘用一句话说清发布进行到了哪一步。

## 这一版有什么

- **写作占满整个页面**：编辑器旁边的侧栏去掉了，文章的设置放在读者看到它们的地方：封面在标题上方，摘要在标题下面，分类、标签、地址、模板和置顶是下面的一排小标签，点开是一个小弹窗。状态、发布时间和删除从顶栏的状态按钮打开。写作时左侧导航自动收起，离开后恢复。
- **就地编辑链接**：光标在链接里时，链接下面弹出一个小气泡，可以改地址、打开或去掉链接；在链接里打字不会再跳到工具栏去。
- **主题设置分页**：主题的每一组设置有自己的页面，旁边是预览。预览会跟到这组设置所在的页面，在任何窗口宽度下都按电脑版排版，改动的地方会短暂地框出来。列表按内容排成行、树或卡片，拖动把手就能排序。
- **一个名字**：初始化页面和 `kite init` 会问你的名字，写成站点的作者；后台在侧栏底部显示它，本地模式显示在站点名称旁边。
- **发布进度一目了然**：仪表盘的发布卡片用一句话说明站点是不是最新的、还差什么，标出每一步的状态，并给出下一步该做什么。
- **设置都摆在侧栏里**：站点、主题和外观直接列在侧栏，不再折叠在「设置」下面，账号在侧栏底部。后台的大部分页面底部多了一行页脚，写着版本号，链接到文档、源码和问题反馈；手机上的顶栏也会显示 Kite 的标志。
- **给主题用的**：高亮的代码块带上 `data-lang`，写着作者标注的语言，主题可以据此给代码块加标题，[风标](https://github.com/kite-plus/theme-vane)就是这样做的。主题设置里的一组可以用 `preview` 指定预览哪个页面：`home`、`post`、`page` 或 `posts`。

## 安装和升级

从 [GitHub Releases](https://github.com/kite-plus/kite/releases/tag/v0.1.1) 下载对应系统的压缩包，解压后把 `kite` 放进 `PATH`，在空文件夹里运行 `kite run`。在 macOS 上，运行 `xattr -d com.apple.quarantine kite` 放行第一次运行。

用 Docker 在服务器上运行：

```bash
docker run -d --name kite --restart unless-stopped -p 127.0.0.1:1717:1717 -v kite-data:/data ghcr.io/kite-plus/kite:0.1.1
```

从 0.1.0 升级，替换程序或者拉取新镜像即可，站点和文件都不用改。作者的名字现在保存在 `site.author` 里；旧的个人资料里存过的名字，在重新保存之前会继续显示。

这个网站也已经用 0.1.1 构建，文档里的代码块顶上会写出「终端」这样的语言名。
