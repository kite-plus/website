Kite 0.1.11 发布了。这一版重画了写作后台：浅蓝色的画布上铺一张白色的纸面，图标统一换成 Phosphor，一篇文章走到了哪一步、还有什么没发布，都摆在明处。

## 这一版有什么

- **晴空外观**：后台用浅蓝色背景搭配白色的内容面板，导航栏顶上是 Kite 的标识；图标统一换成 Phosphor，浅色和深色外观一起调过。
- **仪表盘看写作进度**：按草稿、定时发布、已保存待发布、已上线四站排开，每一站有多少篇、下一步该做什么，一眼看完；下面是最近的文章、写作节奏和常用标签。
- **待发布的改动随时看得见**：导航栏底部会显示还没发布的文件、还没推送的提交和失败的发布，并给出对应的操作。
- **内容列表筛选更直接**：按状态切换并显示数量；文章标题下列出分类和标签，点一下就按它筛选；分类和标签列可以从视图菜单里重新打开。
- **部署页先看发布进度**：先显示保存、提交、推送、部署走到了哪一步，并提供发布全部改动或推送已有提交的入口；连接 GitHub、导出网站和固定 Kite 版本用统一的卡片排列。
- **主题、插件和设置**：应用中心用统一的分类切换，空的插件列表会引你去安装；设置按组排列，界面设置可以选语言、预览外观；编辑器里已经设置的属性更醒目。

## 修复

- 设置页的保存按钮不再落进底部的渐隐里，看起来不会再像是被禁用了。

## 安装和升级

从 [GitHub Releases](https://github.com/kite-plus/kite/releases/tag/v0.1.11) 下载对应系统的压缩包，解压后把 `kite` 放进 `PATH`，在空文件夹里运行 `kite run`。在 macOS 上，运行 `xattr -d com.apple.quarantine kite` 放行第一次运行。

用 Docker 在服务器上运行：

```bash
docker run -d --name kite --restart unless-stopped -p 127.0.0.1:1717:1717 -v kite-data:/data ghcr.io/kite-plus/kite:0.1.11
```

从 0.1.10 升级，替换程序或者拉取新镜像即可，站点已有的东西都不会变。`kite.lock` 固定在旧版本的站点，部署时仍然用旧版本，直到你运行 `kite wrapper`，或者在后台「系统 → 部署」里选择改用新版本构建。
