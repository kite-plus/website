Kite 0.1.4 发布了。这一版把主题定了下来：主题契约冻结为 `kite/v1`，站点能写自己的菜单，主题能在命令行里安装、切换和新建。后台能列出一篇文章的附件，把冲突按三个版本对比，知道服务器是只读的，在手机上也能打开预览。

## 这一版有什么

- **主题契约冻结**：在 `apiVersion: kite/v1` 下模板能调用的东西，每个方法和函数连同签名，列在 [theme-system.md](https://github.com/kite-plus/kite/blob/main/docs/design/theme-system.md) 第 6、7 节，从现在起只增，不改名、不删除、不改签名。用到后来新增的东西的主题，用 `requires` 写明它需要的 Kite 版本。
- **菜单**：站点的菜单写在 `kite.yaml` 的 `menus` 下，不属于哪一个主题，换了主题还在。主题在 `theme.yaml` 里说明它画哪些菜单，后台新增的**设置 → 菜单**负责填写，页面和文章按标题挑选。模板用 `{{ range .Site.Menus.main }}` 画菜单，每个链接都已经带上站点的路径。内置主题在页头画 `main`。
- **在命令行里管理主题**：`kite theme list`、`add`（发布附带的压缩包或一个目录）、`use`、`remove` 和 `new`，检查方式和后台一样。`kite theme new` 写出的小主题，不用改就能通过 `kite theme verify`。
- **文章的附件**：编辑器里的「附件」列出文章目录里会发布的文件，以及每个文件被哪里用到；可以复制链接，原地替换文件，指向它的链接都不用改；删除还在用的文件时会先提醒；也可以再添加。
- **冲突按三个版本对比**：保存时撞上了别处的改动，对话框会列出你加载时的版本、你的版本和存着的版本，逐个部分对比，正文按段落对比；两边改的是不同部分时，会把两边合在一起。合好的内容放进编辑器，不会自动保存，等你看过。
- **只读的服务器**：没有加 `--write` 启动的服务器，后台会在站点名旁标出「只读」，并去掉它会拒绝的操作；浏览、预览、搜索和导出照常可用。
- **保存更安静**：可视化编辑器保存时，一次编辑没碰到的块保持文件里原来的写法，改一个词，diff 也只有一行。
- **手机上的预览**：预览开关在任何窗口宽度下都显示；打开预览时，编辑器里的光标和文字都还在。

## 修复

- 文件在磁盘上改过、保存因此被拒绝时，如果服务器还没读到那次改动，冲突里存着的版本可能显示成你自己的版本，合并或覆盖就会在你看不到的情况下冲掉那次改动。现在冲突显示的是文件当前的样子。用 `--watch=false` 运行时，因为 `kite.yaml` 改过而被拒绝的设置会重新加载，不再一直被拒绝到重启为止。
- 构建只替换 Kite 自己写出的输出目录，或者里面有本站站点地图或订阅的目录；`build.output` 指向放着别的文件的文件夹时，不会再把它清空。
- 不管登录在哪一步过期，发布、预览、上传还是安装主题，后台都会请你重新登录，登录之后，刚才输入的内容还在。
- 没写日期的文章，在内置主题里不显示日期，归档页把它放在「未注明日期」下面，而不是公元 1 年。
- 没有发布时间的草稿，预览时按它发布时会有的日期显示。
- 在手机上，菜单链接和文档树分组的字段不会再被挤得只剩几个字。

## 安装和升级

从 [GitHub Releases](https://github.com/kite-plus/kite/releases/tag/v0.1.4) 下载对应系统的压缩包，解压后把 `kite` 放进 `PATH`，在空文件夹里运行 `kite run`。在 macOS 上，运行 `xattr -d com.apple.quarantine kite` 放行第一次运行。

用 Docker 在服务器上运行：

```bash
docker run -d --name kite --restart unless-stopped -p 127.0.0.1:1717:1717 -v kite-data:/data ghcr.io/kite-plus/kite:0.1.4
```

从 0.1.3 升级，替换程序或者拉取新镜像即可。有几处行为变了：

- 构建不再替换不是 Kite 写出的文件夹，也就是 `.kite/outputs` 里没有记录、里面也没有本站 `sitemap.xml` 或 `rss.xml` 的文件夹。把 `build.output` 指向一个专用的文件夹，或者先把它清空一次。输出目录旁边的临时文件夹现在叫 `<output>.kite-stage` 和 `<output>.kite-previous`。
- 内置主题升到 0.7.0：站点写了 `main` 菜单以后，页头画的是这个菜单，在那之前显示它自己的链接。
- `partialCached` 接受 Hugo 那样写在数据后面的变体键，画出的 partial 和 `partial` 一样。
- 画菜单的主题需要这个版本，写 `requires: ">=0.1.4"`。

这个网站也已经用 0.1.4 构建，文档里补上了[菜单](/writing-themes/#菜单)、[在命令行里管理主题](/using-themes/#在命令行里管理)和[主题契约](/writing-themes/#主题契约)。
