Kite 0.1.12 发布了。从这一版起，有新版本时 Kite 会提醒你。写作后台也继续打磨：编辑器只剩一个发布按钮，部署页一次只看一种发布方式，旁边是一张上线前检查清单；分类、标签、设置和登录页都重新整理过。

## 这一版有什么

- **新版本提醒**：发布版的 `kite serve` 和 `kite run` 每天最多问一次 GitHub 有没有更新的版本。有新版本时，服务启动时和日志里会提示；后台在每个浏览器里提示一次，「系统 → 部署」的上线前检查里也会一直显示，附上更新内容和升级方法，在容器里就提示拉取新镜像。它只负责提醒，不会自己替换程序，也不会改 `kite.lock`。设置 `KITE_NO_UPDATE_CHECK=1` 可以关掉，见[固定 Kite 版本](/kitew/)。
- **编辑器只有一个发布按钮**：已发布文章顶上的「保存」和「更新」合成了「发布改动」，保存并上线；只想保存，用按钮旁小箭头里的「只保存，不发布」，或者照旧按 ⌘S / Ctrl+S。没有可发布的改动时按钮是灰的，已保存但还没发布的文章，标题下会标出「未发布」。
- **部署页一次看一种方式**：先选「推送到 Git」还是「导出 zip」，已经在 git 仓库里的站点默认看推送。右边的上线前检查列出站点地址、内容能不能读出、Kite 版本和待发布的改动，每一行都能展开看原因和改法；连接 GitHub 的表单点「开始连接」才展开。
- **分类和标签重新设计**：分类是一张张卡片，带最近 12 个月的发布节奏和最新的 3 篇；标签平铺成一面墙，点开就能看用到它的文章，改名、合并、删除也在这里。
- **设置页按路线分段**：每个设置页按编号分段，标出改过的和需要改的地方；撤销和保存放在标题行；输入框、开关和选择器换成了统一的样式。
- **侧栏可以拖宽**：拖动侧栏边缘调整宽度，拖到足够窄就收起，宽度会被记住。
- **更多细节**：没写名字时账户卡片显示风筝头像，退出登录放进了账户卡片；登录页和新建站点页换成浅蓝背景上的白色卡片；今年的日期不写年份；应用中心的主题截图加载时显示主题名，不再是一块灰。

## 修复

- 每个设置页在浏览器标签上显示自己的名字。
- 设置页底部的渐隐只在下面还有内容时出现，不会挡住按钮。
- 保存文章之后，导航栏底部的待发布卡片立刻更新，不用等下一次检查。

## 安装和升级

从 [GitHub Releases](https://github.com/kite-plus/kite/releases/tag/v0.1.12) 下载对应系统的压缩包，解压后把 `kite` 放进 `PATH`，在空文件夹里运行 `kite run`。在 macOS 上，运行 `xattr -d com.apple.quarantine kite` 放行第一次运行。

用 Docker 在服务器上运行：

```bash
docker run -d --name kite --restart unless-stopped -p 127.0.0.1:1717:1717 -v kite-data:/data ghcr.io/kite-plus/kite:0.1.12
```

从 0.1.11 升级，替换程序或者拉取新镜像即可，站点已有的东西都不会变。`kite.lock` 固定在旧版本的站点，部署时仍然用旧版本，直到你运行 `kite wrapper`，或者在后台「系统 → 部署」的上线前检查里改用 0.1.12 构建。

这个网站也已经改用 0.1.12 构建。
